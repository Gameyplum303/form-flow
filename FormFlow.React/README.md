# FormFlow.React

The React 19 + TypeScript client for taking FormFlow surveys. It needs the API running (see the [main README](../README.md#run-it-locally)).

```bash
npm install
npm start          # http://localhost:3000
npm run lint
npm run build      # production build in build/
```

Set `REACT_APP_API_URL` to use an API somewhere other than `http://localhost:5164`.

Tests are in [`../FormFlow.React.Tests`](../FormFlow.React.Tests). Component documentation: [docs/react-components.md](../docs/react-components.md).
